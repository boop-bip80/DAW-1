# LiVi Wave app icon

A glowing glass tile (teal to violet) with a stylised waveform and level-meter dots behind the
"LiVi" wordmark. It was generated with Google Gemini from the owner's prompt and supplied by the
owner as `source/liviwave-icon-source.png` (a 2752 × 1536 banner). The icon is a square crop of the
tile in the middle of that banner; the generator's watermark sits outside the crop.

## Geometry

Crop box (source pixels): x 877, y 265, 1000 px square, scaled to 1024 and masked to the
tile's own rounded corners (inset 36/21/35/21 px, 112 px radius) so the corners are transparent. Windows and
Linux use that tile as is. The macOS icons (`liviwave.icns`, `liviwave-macos-512.png`) sit on
Apple's grid: an 824/1024 body with a transparent margin.

## Provenance and licence

AI-generated by the owner; no third-party image was traced or copied. Released MIT OR Apache-2.0
like the code, as the owner chooses (see `ATTRIBUTION.md`).

## Files

| File | What it is |
|---|---|
| `source/liviwave-icon-source.png` | The generated banner the icon is cropped from |
| `icon.svg` | SVG wrapper around a 512 px PNG of the tile (the scalable icon) |
| `liviwave-1024.png` | 1024 px master with transparent rounded corners |
| `liviwave-macos-512.png` | Runtime window/Dock icon on macOS (Apple grid margin) |
| `liviwave.icns` | macOS bundle icon (128–1024 px PNG entries) |
| `liviwave.ico` | Windows icon (16–256 px), embedded in `liviwave.exe` and used by the MSI |
| `hicolor/<size>x<size>/apps/ai.storyteller.liviwave.png` | Linux/FreeBSD icon theme, 16–512 px, plus `scalable/` |

`packaging/icons.sh` renders the set from `icon.svg` (needs `resvg`; `iconutil` on macOS for the
`.icns`). Because `icon.svg` now wraps a raster, prefer re-cropping from the source image.
